# Purpose

I'm making this repo to compile coding questions and answers to get used to coding by myself again. Most of these questions will have multiple answers done in different languages so that I can refer to when I need to study for coding interviews. This is also mainly to combat the AI fatigue and burnout I have at the moment.

Each question will be its own folder and have its structure that consists of a markdown file to serve as notes and a folder dedicated to the answers. The markdown file will contain notes and pointers for myself. Each answer file will be named after the language I used.

I plan to tackle at least one question a day. The question of how many languages depends on my confidence and mood on that day. I will date each language in the notes markdown file so I know if I've returned to it later on. If all languages were answered on the same day, a simple sentence stating so will be written above. Otherwise, they will be dated as usual.

Most of the questions will come with answers I've either attempted or found while studying. Regardless, they include explanations of my own understanding of the language it is written in. Further explanation may be included in its own separate markdown file if it gets too long. Otherwise, they will mainly be explained in the file itself through the comments.
