# Purpose

I'm making this repo to compile coding questions and answers to get used to coding by myself again. Most of these questions will have multiple answers done in different languages so that I can refer to when I need to.

Each question and answer will be its own folder and have its own markdown file. The markdown file will contain notes and pointers for myself. Each answer file will be named after the language I used.

I plan to tackle at least one question a day. The question of how many languages depends on my confidence. I will date each language in the notes markdown file so I know if I returned to it later on.
